# Gafin Bagoes Syahputra — Portfolio

Personal portfolio website built with Next.js, TypeScript, Tailwind CSS v4, Framer Motion, and Lucide.

## Run locally
1. Install Node.js 20.9 or newer.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

## Deploy to Vercel
Upload this project to a new GitHub repository, then import that repository in Vercel. Vercel detects Next.js automatically.

## Personalize before publishing
- Replace the placeholder GitHub and Instagram links in `app/page.tsx`.
- Replace `hello@example.com` with your real contact email.
- Add real project descriptions in the Projects section.
- The portrait is already installed at `public/images/gafin.png`.

The supplied portrait is included; you do not need to upload it separately.
